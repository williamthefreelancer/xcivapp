# `/events/{slug}` 404 for Woo event products

| What | Path / slug | Impact | Status |
|------|-------------|--------|--------|
| Classic WP had no event CPT for catalog products; Nuxt/cards linked `/events/{slug}` | City Club, invite-only, public immerse routes, workshop | Direct `/events/…` URLs 404'd on XAMPP | fixed |
| Redirect maps `/events/{slug}` → product when no published `event` CPT | `snf_redirect_event_path_to_product()` in `app/Services/events.php` | 301 to `/product/{slug}/` landings | fixed |
| Gathering card hard-coded `/events/the-city-club-private-party` | `snf_get_upcoming_gathering_cards()` in `app/Services/home.php` | Now uses `snf_get_city_club_private_party_url()` | fixed |

Legacy alias `the-eight-hundred-plus-journeys` resolves via `snf_resolve_listing_product_slug()`.
