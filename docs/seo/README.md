# Technical SEO — Super Ninety Four

Operational playbooks so every site update stays indexable, answer-engine ready, and paid-channel safe.

Use these when you:

- Ship a page, event, or theme change
- Need daily fixes because ads / organic / listings are underperforming
- Change something that could break search, ads, or calendars later

## Folders & files

| File | Use when |
|------|----------|
| [CHECKLIST-AFTER-EVERY-UPDATE.md](./CHECKLIST-AFTER-EVERY-UPDATE.md) | After any public-facing deploy |
| [INDEXING.md](./INDEXING.md) | Google / Bing / crawl / sitemap issues |
| [AEO.md](./AEO.md) | ChatGPT, Perplexity, AI Overviews, answer engines |
| [SEM-PAID-SEARCH.md](./SEM-PAID-SEARCH.md) | Google Ads / Bing Ads media buying |
| [X-ADS.md](./X-ADS.md) | X (Twitter) Ads |
| [EVENT-CALENDAR-SUBMISSIONS.md](./EVENT-CALENDAR-SUBMISSIONS.md) | Paid event listing calendars |
| [MOBILE-TABLET.md](./MOBILE-TABLET.md) | Phone / tablet UX & Core Web Vitals |
| [DAILY-MARKETING-RECOVERY.md](./DAILY-MARKETING-RECOVERY.md) | Marketing not working — triage same day |
| [CRITICAL-CHANGES-LOG.md](./CRITICAL-CHANGES-LOG.md) | Log URLs, titles, redirects, tracking IDs |

Companion structured data lives in [`../schema/`](../schema/).

## Quick rule

**Public URL changed?** Update: sitemap → Search Console → schema → ads final URLs → calendar listings → this log.
